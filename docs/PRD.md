# Product Requirements Document

## 제품명

SNS Commit

## 한 줄 설명

SNS 게시물을 여러 채널에 안전하게 재사용하도록 돕는 크로스포스팅 워크스페이스.

## 배경

운영자는 같은 콘텐츠를 여러 SNS에 반복 게시하지만, 플랫폼별 이미지 규격, 글자 수, 링크 처리, 해시태그 문화가 달라 매번 수작업이 필요합니다. 특히 Instagram에서 만든 콘텐츠를 KakaoStory 같은 채널로 옮길 때 사진 저장과 본문 복사가 분리되어 피로도가 큽니다.

## 목표

- 원본 게시물 재사용 시간을 줄인다.
- 채널별 형식 오류를 게시 전에 발견한다.
- 공식 API 기반 자동 발행과 수동 게시 보조를 구분한다.
- 게시 이력을 남겨 운영자가 무엇을 어디에 올렸는지 확인할 수 있게 한다.

## 비목표

- 플랫폼 약관 우회 자동화
- 무단 스크래핑
- 타인의 게시물 대량 복제
- 모든 SNS 일괄 지원

## 페르소나

### Persona A. 로컬 매장 운영자

- 신상품, 이벤트, 휴무 공지를 반복 게시한다.
- 디자인 도구와 SNS 앱 사이를 오가는 시간이 부담스럽다.
- 성공 기준: 인스타그램 게시물을 5분 안에 다른 채널에도 게시한다.

### Persona B. 1인 크리에이터

- 사진과 긴 캡션을 여러 채널에 맞게 다듬는다.
- 게시물별 성과보다 발행 루틴 단축이 중요하다.
- 성공 기준: 원본 게시물 하나로 채널별 초안을 빠르게 만든다.

### Persona C. 마케터

- 게시 실패와 누락을 관리해야 한다.
- 계정 연결, 권한, 토큰 만료 이슈를 투명하게 보고 싶다.
- 성공 기준: 발행 상태와 실패 원인을 한 화면에서 확인한다.

## 사용자 스토리

- 사용자는 Instagram 계정을 연결해 최근 게시물을 가져올 수 있다.
- 사용자는 원본 게시물을 선택해 대상 채널별 초안을 만들 수 있다.
- 사용자는 초안의 본문, 해시태그, 이미지 순서를 수정할 수 있다.
- 사용자는 게시 전 채널별 제한 위반을 확인할 수 있다.
- 사용자는 Instagram 대상 초안을 발행 요청할 수 있다.
- 사용자는 KakaoStory 대상 초안의 본문을 복사하고 이미지를 내려받을 수 있다.
- 사용자는 발행 성공, 실패, 재시도 상태를 볼 수 있다.

## 기능 요구사항

### Auth

- Supabase Auth 기반 이메일 로그인
- 사용자별 프로필 자동 생성
- RLS 기반 데이터 격리

### Social Account Connection

- Instagram OAuth 연결
- 계정 유형, 권한, 토큰 만료 상태 저장
- 연결 해제

### Source Import

- 연결된 Instagram 계정의 최근 게시물 목록 조회
- 이미지, 캡션, permalink, timestamp 저장
- 중복 import 방지

### Composer

- 원본 게시물 기반 초안 생성
- 대상 채널 선택
- 이미지 선택/제외/순서 변경
- 본문 수정
- 해시태그 분리 편집
- 채널별 제한 검사

### Publishing

- Instagram 공식 API 발행 요청
- 발행 작업 상태 저장
- 실패 로그 저장
- 재시도
- KakaoStory 수동 게시 가이드 제공

## 비기능 요구사항

- 주요 화면 LCP 2.5초 이하 목표
- 모든 DB 테이블 RLS 활성화
- 외부 API 실패 시 사용자 친화적 오류 제공
- 토큰과 API secret은 클라이언트 번들에 포함하지 않음
- 게시 작업은 멱등성 키로 중복 발행 방지

## MVP 수용 기준

- 사용자가 로그인 후 Instagram 계정을 연결할 수 있다.
- Instagram 게시물을 최소 20개까지 불러올 수 있다.
- 게시물 하나를 선택해 KakaoStory용 수동 게시 패키지를 만들 수 있다.
- Instagram용 초안을 만들고 발행 작업을 생성할 수 있다.
- 발행 성공/실패 상태가 대시보드에 표시된다.
- 토큰 만료 또는 권한 부족 시 복구 가이드가 표시된다.

## 운영 지표

- Activation: 첫 원본 게시물 import 완료
- Aha Moment: 첫 채널별 초안 생성
- Conversion: 첫 게시 완료
- Retention: 7일 내 두 번째 게시물 재사용
- Reliability: 발행 작업 성공률

## 출시 전 체크리스트

- Instagram 앱 심사 요구사항 확인
- KakaoStory 수동 플로우 법무 검토
- 개인정보 처리방침 작성
- 서비스 약관 작성
- Supabase RLS 테스트
- 토큰 암호화 전략 확정
- 실패 재시도 정책 확정
