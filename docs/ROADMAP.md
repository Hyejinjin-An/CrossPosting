## 릴리즈 마일스톤

### M0. Design Lock

- PRD 승인
- 정책 리스크 승인
- 데이터 모델 승인
- 핵심 화면 와이어프레임 승인

### M1. Internal Alpha

- 로그인 가능
- Instagram 계정 연결 가능
- 원본 게시물 import 가능
- KakaoStory 수동 게시 패키지 생성 가능

### M2. Closed Beta

- Instagram 발행 가능
- 실패 로그와 재시도 가능
- 5명 이상 실제 사용자 테스트
- 개인정보 처리방침과 약관 준비

### M3. Public Beta

- 온보딩 개선
- 결제 전환 실험
- 운영 대시보드
- Sentry 기반 오류 모니터링
